# Claudinho-impress-es
Soluções de impressão

## TravaCalor

Limita o calor (darkness) da impressora de etiquetas ELGIN L42 PRO FULL, mesmo
quando o programa de realocação manda as preferências no máximo e corta o ribbon.

Como usar: baixe a pasta [`TravaCalor`](TravaCalor), abra o
`ABRIR TRAVACALOR.bat` e siga os 3 passos da janela (escolher a impressora
conectada, conferir/alterar os nomes, ajustar o calor máximo).
Detalhes em [`TravaCalor/LEIA-ME.txt`](TravaCalor/LEIA-ME.txt).
